## CUDA preparation and evidence

`tools/train_distill_cuda.py` imports the pinned original NL2SH GGUF rather than substituting base Qwen weights. Source SHA-256 matches issue #8 (`6f8a17a11129a31074c944f4c2602453fafd9de43bdaeb1630a8f511ec820f71`). It uses exact GGUF tensor coverage, preserves float32 biases/norms, applies rank-8 LoRA to all seven linear modules in the final 16 layers (scale20 / PEFT alpha160), masks the serving prompt, and supervises command or empty-answer end-of-turn tokens. Seed42, batch1, maximum sequence512, AdamW learning rate1e-5, 1,000 steps are recorded before any training choice. Training uses bfloat16 autocast on the 5090; original frozen weights keep their import dtype.

The real CUDA zero-update import/merge preserved all 338 tensor digests, ignoring signed zero; `docs/cuda-zero-roundtrip.json` records the check. It is not a backward or optimizer-update test and does not measure training memory. A Q4_K_M zero-update artifact was produced with llama.cpp b11565 and transferred to the Mac with SHA-256 verified (`099c2c7dd8da83eb83869e2b6a00caafffb3a707601bc5a267265892c1d4b4ce`). The paired check now passed: no per-case label flips across all 61 dev and 80 everyday cases. The produced GGUF also passed the 62-case byte/token and empty-EOS prompt audit. The old feasibility quantizer was b10333; the build change is recorded rather than assumed equivalent.

The verified-label builder refuses non-Mac hosts, verifies parsed complete teacher commands through the serving lint/deletion/placeholder/DANGER checks, requires 3-of-5 agreement, and quarantines any row whose request is near-identical to an evaluation request (word Jaccard >= 0.7) or whose normalized command (tool, flags, non-path operands; shell glue such as `echo`/`[` ignored) matches an evaluation reference; a bare tool+flags overlap inside a pipeline is reported, not gated (a lone bare command is gated). Rows named in `data/distill/quarantine_ids.txt` (paraphrases of evaluation intents found in review) are always excluded. No-command target is empty assistant content with end-of-turn supervision. A Mac integration probe injected an empty completed server response into the real upstream generation path and confirmed `unsupported` with no command; `docs/distill-prompt-audit.json` is the completed Mac evidence.
